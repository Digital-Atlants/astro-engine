## Ответы на три вопроса совета — они меняют правила импорта

1. **Импорт — только русский.** Статус в этой таблице относится к колонке
   `ru`. Колонки en / uk / de **не импортируются вообще**, пока задача
   перевода не добавит им собственные статусы. Поэтому пометка «(second
   phrasing)» в нерусских колонках безопасна, и 19 строк парафраз
   утверждены: русский в них финальный.
2. **Система деканов.** Движок не знает систем деканов — он считает
   геометрические трети знака по 10°, ключ `decan.<sign>.<third>`. Чем
   окрашивать треть — вопрос только текста. Принята система по тригонам,
   замена на халдейскую не нужна.
3. **Кнопки.** Варианты ответа — отдельные чипсы. **В чипс попадает
   только заголовок сферы — часть до двоеточия** («Один на один»); полная
   строка «Заголовок: расшифровка» идёт в текст вопроса. Так формат совета
   решает и вёрстку на мобильном.

## Правила, по которым написаны атомы (решение совета)

1. **Шаблоны держат согласование на фиксированном слове** («тема», «это»);
   атом вставляется в кавычках в именительном падеже.
2. **Сфера дома = «Заголовок: расшифровка», ≤ 12 слов**; соседние дома не
   делят ключевых слов.
3. **Тема планеты — именительный падеж, без жаргона.**
4. **Декан = 3–4 признака: ≥ 2 внешности + ≥ 1 манеры**, система по
   тригонам, тройки внутри знака различаются первым признаком и уравнены
   по привлекательности; слова «полнота», «невысокий», «ленивая»,
   «тяжеловатая» не используются.
5. **Портреты без грамматического рода:** `portrait` — глаголы во 2-м лице
   множественного числа, `portrait_contrast` — «Первое впечатление: …».
6. **`paraphrase` — та же черта, другая картинка**, не перестановка слов.
7. **Ни одного названия знака или стихии в тексте вопроса.** Знающие свой
   знак отвечают по стереотипу знака (van Rooij, 1994); без этикетки ответ
   честнее.

## Что делает движок и веб с этим файлом (не текстовые решения)

- **Собранные фразы проверяет тест в CI**, не владелец: веб собирает по
  6 фраз на каждый шаблон из случайных атомов и проверяет их против
  шаблона согласования. Ручная вычитка — не контроль качества.
- **Доверие деканному каналу по умолчанию ниже знакового** — константа
  конфига движка: декан на широте 51° восходит от 18 до 57 минут, и
  самоотчёт такой точности не даёт. Вес пересматривается только по
  измерениям.
- **Детектор самоописания по солнечному знаку** — пункт спеки движка:
  движок знает солнечный знак по дате; если ответы первого этапа сложились
  в стихию и крест солнечного знака, это чаще стереотип, чем восходящий
  знак (честное совпадение — один случай из двенадцати).
- Точность вопросов (узнаёт ли человек свою треть) **не измерена**.
  «Approved» означает: согласовано с традицией, грамматично, без рода, пары
  уравнены. Лог ответов ведёт телеметрия; отдельная калибровка не ведётся
  по решению владельца.

**Словарь для следующего редактора.** *mover* — планета, которая в
пределах окна неопределённости времени рождения попадает в разные дома;
вопрос про неё выбирает дом. *decan / third* — треть знака (10°).
*атом* — одна фраза, из которой клиент собирает много вопросов. *facet* —
вариант формулировки одной черты (`label` / `paraphrase`, `portrait` /
`portrait_contrast`). *approved* — русская строка уходит в приложение.

**Отложенная гипотеза (не в этом файле):** поле «год» у вопроса

атрибуцией к дому, сделанной самим человеком. Событийный канал провалился
именно на атрибуции, не на датах. Проверять измерением, как все добавления
в движок.
